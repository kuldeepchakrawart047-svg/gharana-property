# Gharana — Property Website

A responsive real-estate landing page template with subtle animations and interactive UI.

## Run it
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. For local development, you can also run a simple server from this folder, e.g. `python -m http.server 8000`.

## Features
- Responsive desktop and mobile layout
- Scroll reveal animations and floating hero label
- Property cards with sale/rent filters
- Search by property type and location
- Save/favourite buttons with toast feedback
- Property details modal
- Contact form UI with demo confirmation
- Reduced-motion accessibility support

## Customize before publishing
- Replace sample listings, prices, locations, phone and email with verified details.
- The enquiry form is front-end only; connect it to a backend, email service or CRM to receive submissions.
- Images and Google Fonts are loaded from external URLs and need an internet connection.
- Change colors and fonts in `style.css` using the CSS variables at the top.
